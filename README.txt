#SPREADSHEET DATA CLEANING AND QUALITY IMPROVEMENT

PROJECT OVERVIEW:
This project demonstrates how raw spreadsheet data can be reviewed, corrected, and prepared for more reliable analysis.

OBJECTIVE:
1. Clean and prepare raw product dataset
2. Improve data quality for analysis
3. Create SEO-friendly short_title

PROBLEMS FOUND:
1. Duplicate records
2. Inconsistent text format and extra spacing
3. Unwanted text (html tags, symbols)
4. Unknown language character
5. Long and unstructured titles and details
6. Unusal long product naming
6. Blank spaces (Bullet_point, Description, Product_type ID)

DATA CLEANING PROCESS:
Raw Dataset: 3,848 rows with issues:
- 179 unknown products
- 274 duplicate record
- Invalid item-naming formats

WHAT I CLEANED:
1. Removed duplicates data using Excel Remove Duplicates
2. Handled blank spaces (using the unavailable title) to avoid errors during analysis
3. Standardized inconsistent entries (Case, spacing, symbols, html tags) and Fixed data formats
4. Reduced extra long title, description and bullet_points into reasonable details
5. Titled Unknown language character into Product unknown language content, for consistency during analysis
- Result: 3,573 clean rows in processed_dataset

TRANSFORMATION:
1. Extracted key product info
2. Removed Unnecessary words
3. Limited to 70 characters

RESULTS:
1. Clean, structured dataset
2. Improved readability and consistency
3. SEO-optimized short_title column added
4. New short_title length gotten
5. Descriptive Statistics of Product_ID, type_id, Products lengths

TOOLS USED: 
Microsoft Excel, spreadsheet formulas and functions 

KEY FEATURES:
1. Before-and-after data comparison.
2. Proper product naming
3. Duplicate identification.
4. Text standardization.
5. Missing value review.
6. Data quality checks.
